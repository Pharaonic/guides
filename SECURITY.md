# Security Policy

This repository holds written guides, not executable production software, but guides can still cause harm. Report privately:

- links that lead to malicious or compromised sites;
- example code that is unsafe to copy, such as injection-prone queries or weak cryptography presented as safe;
- security advice that is wrong or outdated;
- vulnerabilities in this repository's workflows or validation tooling.

## Reporting

Please do **not** open a public issue. Use GitHub's private vulnerability reporting for this repository: [Report a vulnerability](https://github.com/Pharaonic/guides/security/advisories/new).

Include the guide URL or path, the problem, and its potential impact. Reports are reviewed before any public correction is made.

Vulnerabilities in a Pharaonic package belong in that package's own repository.
